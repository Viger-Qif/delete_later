# Исследование учебной системы — evidence-first + LLM-RAG

## Вывод

Для переговорного тренажёра недостаточно общего итогового балла. Учебная система должна:

1. находить ошибку на конкретном ходу;
2. показывать точную цитату из реплики пользователя;
3. объяснять тактическое последствие;
4. предлагать улучшенную формулировку;
5. дать пользователю переиграть ход;
6. проверить перенос навыка в новом контексте;
7. сохранять результат в профиле освоения.
8. разделять быстрый детерминированный сигнал, LLM-объяснение и итоговую рекомендацию;
9. проверять grounding и валидировать каждую ссылку/кандидата до показа пользователю.

## Что применено в проекте

### ACE: LLM-based Negotiation Coaching System

ACE разделяет turn-based feedback на три операции:

- error identification;
- direct feedback;
- utterance revision.

В текущем этапе Negotiation Lab это реализовано как поле `evidence` в итоговом анализе. Каждое наблюдение содержит `turn_index`, точную цитату, действие, навык, объяснение, улучшенную реплику, связанные материалы и confidence.

Источник: https://aclanthology.org/2024.emnlp-main.709.pdf

### AI as a Coach in Negotiations

Исследование разделяет поддержку до переговоров, во время и после. Для нашего продукта основная персонализация должна происходить после сессии и в короткой тренировке. Во время разговора не следует перегружать пользователя постоянными подсказками.

Источник: https://direct.mit.edu/ngtn/article/doi/10.1162/NGTN.a.63/136536/AI-as-a-Coach-in-Negotiations-Harnessing

### Intelligent Tutoring System for Negotiation Skills Training

Нужно оценивать не только исход сделки, но и наблюдаемые действия: вопросы, обмен информацией, создание и получение ценности. Персональная обратная связь должна быть связана с конкретным поведением.

Источник: https://par.nsf.gov/servlets/purl/10119673

### AI-Assisted Negotiation Instruction

Одной коррекции ошибки недостаточно. Пользователь должен остановиться, осмыслить ход, попробовать новую стратегию и увидеть последствия. Поэтому evidence-first анализ является промежуточным звеном между симуляцией и повторной практикой, а не финальным отчётом.

Источник: https://direct.mit.edu/ngtn/article/doi/10.1162/NGTN.a.70/137189/AI-Assisted-Negotiation-Instruction-Ten-Key

### RAG в образовательном коуче

Новые материалы по RAG tutoring подтверждают важное разделение: retrieval повышает курс- и предметную согласованность, но сам по себе не делает обратную связь педагогичной. Поэтому в проекте LLM получает одновременно:

- конкретное задание и его rubric;
- ответ пользователя;
- ограниченный набор релевантных SPIN-чанков;
- инструкцию отвечать только в рамках текущего навыка;
- запрет выполнять команды из retrieved text;
- проверку `knowledge_refs` по существующим ID.

Для будущей калибровки нужны не только Recall@K, но и precision, faithfulness, citation accuracy, полезность шага и session-level результат. Отдельно важно проверять, исправил ли пользователь ответ после feedback, а не только понравился ли ему текст.

Источники:

- https://arxiv.org/html/2605.12988v1
- https://arxiv.org/html/2407.12687
- https://arxiv.org/html/2504.14891v1
- https://arxiv.org/html/2402.14594

### Разделение LLM по этапам

В Negotiation Lab используются разные бюджеты и требования:

| Этап | Режим | Задача | Защита |
|---|---|---|---|
| Ход симуляции | быстрый dialog model | роль оппонента и переход графа | JSON schema, сценарий и скрытое состояние отдельно |
| Подсказка | dialog/auto | один следующий ход | RAG ограничен этапом и вопросом |
| Итоговый разбор | smart model | evidence-first персональный разбор | цитата обязана находиться в транскрипте |
| Учебный coach | opt-in LLM-RAG | объяснить конкретный ответ | rubric + SPIN context + valid IDs |
| Рекомендация | smart model | выбрать следующий drill из белого списка | LLM не может создать новый exercise_id |

Если LLM недоступна, пользователь всё равно получает детерминированный ответ по rubric. Это лучше, чем скрытая деградация качества или пустой экран.

## Ограничения текущего этапа

- evidence пока формирует LLM или безопасная эвристика для очевидной ранней презентации;
- confidence ещё не откалиброван по экспертной выборке;
- confidence LLM-коуча ещё не откалиброван по экспертной выборке;
- для production-оценки нужен набор размеченных диалогов и сравнение с экспертами.
