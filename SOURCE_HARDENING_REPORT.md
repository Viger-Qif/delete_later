# Negotiation Lab v21.21 — source, UX and launcher hardening report

Дата: 26.09.2026

## Выполнено

- Изолированы анонимные посетители: отдельный `anon_*` principal и `HttpOnly` cookie.
- В production `Secure` для auth cookie включается принудительно.
- Чужие идентификаторы сессий возвращают 404 и не раскрывают существование записи.
- Добавлено удаление аккаунта, сессий, агрегатов, учебного прогресса и черновиков.
- Учебные ответы, feedback и тексты рефлексий больше не сохраняются в БД.
- Исходный подробный контекст пользовательского сценария по умолчанию не сохраняется.
- Добавлены универсальный semantic quality gate и минимум две содержательные развилки.
- Узлы получили `why_needed` и `rationale_source`.
- Добавлена политика модерации и проверки до/после генерации.
- Replay переведён на браузерную историю с одноразовым временным контекстом.
- Удалён мёртвый код автоматического завершения голосовой сессии по тишине.
- Ключевой пользовательский текст на learning/session/results поднят до 14 px.
- Технические RAG/model-индикаторы скрыты из пользовательской сессии.
- Добавлен единый русский mapper сетевых ошибок.
- Разделены таймауты dialog/smart; компактный JSON-промпт устраняет обрыв больших графов.
- Добавлено явное завершение/возврат из чата, включая ноль отправленных реплик.
- Главная, чат и статистика получили затемнённые пошаговые туры Фиделины.
- Учебный режим оформлен как последовательный курс SPIN: теория, вводные уроки, практика, разбор и повтор.
- Туры ожидают динамические цели, используют новые ключи прогресса и не зависят от старого browser cache.
- Windows/macOS/Linux launchers проверяют `.venv`, восстанавливают отсутствующий pip и поддерживают Python 3.12/3.13 без ручного редактирования.

## Проверки

- `53 passed`, одно известное предупреждение Starlette о будущем `httpx2`.
- Learning validator: 19 упражнений, 5 gold cases.
- Synthetic SPIN gold: 25 cases.
- RAG Recall@3 = 1.0, Recall@5 = 1.0.
- `compileall` и `node --check` пройдены.

- Live API:
  - dialog JSON → `google/gemini-3.1-flash-lite`;
  - smart JSON → `deepseek/deepseek-v4-pro`;
  - полный граф после оптимизации: 6–7 узлов, 3–4 содержательные развилки, semantic gate passed.
